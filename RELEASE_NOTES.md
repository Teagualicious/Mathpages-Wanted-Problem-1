# v1.0.0 - Reproducibility package

This release contains the complete peer-review package for the 29-bit MathPages Wanted Problem 1 counterexample:

- a self-contained LaTeX proof and rendered PDF;
- dependency-free Python and JavaScript BigInt verifiers;
- original exhaustive-search source and raw output, unchanged;
- an independent all-collision audit and complete rerun logs;
- search methodology, normalization and coverage documentation;
- provenance and a redacted transcript summary;
- SHA-256 integrity hashes, citation metadata, MIT license, and CI.

## Claim boundaries

- **Validity:** proved and mechanically reproduced.
- **29-bit minimality:** false for the MathPages problem as stated; the audit records a 21-bit pair missed by the original equal-popcount filter.
- **Historical novelty:** not claimed; it requires literature review and confirmation from the problem maintainer.
